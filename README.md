Test de verificare – GitHub
1. Ce este un depozit și ce conține în plus față de un folder obișnuit de pe calculator?

Un depozit (repository) este un spațiu unde se păstrează fișierele unui proiect. În plus față de un folder obișnuit, acesta păstrează istoricul modificărilor și informațiile despre commit-uri.

2. Ce este un commit? Ce informații înregistrează GitHub la fiecare commit?

Un commit este o salvare a modificărilor făcute în proiect. Acesta înregistrează modificările, autorul, data și mesajul commit-ului.

3. Care sunt regulile GitHub pentru parolă și pentru numele de utilizator?
- Parola: trebuie să fie sigură, suficient de lungă și greu de ghicit.
- Numele de utilizator: poate conține litere, cifre și cratime, nu poate începe sau termina cu o cratimă și nu poate conține spații sau caractere speciale nepermise.
4. Dintre numele de utilizator ana-ionescu, -ana-, ana ionescu și ana_ionescu, care sunt acceptate de GitHub? Se justifică răspunsul pentru fiecare.
- ana-ionescu – acceptat, deoarece cratima este între cuvinte.
- -ana- – neacceptat, deoarece începe și se termină cu o cratimă.
- ana ionescu – neacceptat, deoarece conține un spațiu.
- ana_ionescu – neacceptat, deoarece caracterul _ nu este permis în numele de utilizator GitHub.
5. Ce se face pe calculatorul din laborator la sfârșitul orei și de ce?

Se închide sesiunea contului personal și se șterg fișierele personale descărcate, pentru a proteja datele și contul.

6. Prin ce diferă un depozit Public de unul Private? Care se alege pentru portofoliu și de ce?
- Public: poate fi văzut de oricine.
- Private: poate fi accesat doar de proprietar și de persoanele autorizate.
Pentru portofoliu se alege Public, deoarece profesorul și alte persoane pot vedea lucrările publicate.

12. Care sunt pașii de activare a GitHub Pages? Ce fișier este prima pagină a site-ului?
1. Se intră în depozitul GitHub.
2. Se accesează Settings → Pages.
3. Se alege sursa de publicare, de exemplu Deploy from a branch.
4. Se selectează ramura main și folderul / (root).
5. Se apasă Save.
Prima pagină a site-ului este fișierul index.html.
